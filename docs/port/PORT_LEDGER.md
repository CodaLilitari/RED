**How to read the status column.** `Present` means the rewrite already
implements the contract (possibly under a different name). `Partial` means a
usable substrate exists but at least one named Coda invariant is unproven or
missing. `Absent` means no code path exists. Status is judged against the
Coda **contract** (CODA_FEATURES.md §F-xx), not against feature-name overlap:
e.g. the rewrite's COG *editor* does not make F-10 `Present`, because F-10's
contract is guarded typed binding, which the editor lacks
([COG_SLICE_SPEC.md](COG_SLICE_SPEC.md) §2.3 G-3).

**Difficulty scale.** S = days, single file area, existing seams. M = one
subsystem, new core module + tests. L = cross-subsystem or new executable +
protocol. XL = external dependency (engine build) or multi-phase programme.
Every rating carries its reason; downgrade only with new evidence.

## 6. Cross-cutting invariants (apply to every row)

From [CODA_FEATURES.md](CODA_FEATURES.md) "Cross-cutting invariants" — these
are port requirements, not per-feature options:

1. **Plan/apply separation** — planning mutates only an isolated document;
   committing binds to the reviewed `outputSha256` (+ `resourceRevision` /
   `sourceRevision` where applicable) and creates a new file atomically. No
   overwrite flag exists anywhere.
2. **Revision binding** — numeric selectors and spatial tokens are valid only
   for the exact `inputSha256` / `sourceRevision` they were issued from.
3. **Bounded everything** — requests (1 MiB), pages (default 50, max 200),
   operations (≤1000 CLI / ≤128 MCP), archives, feeds, bakes. Exceeding a
   bound refuses; nothing truncates silently.
4. **Refuse, don't guess** — ambiguity, staleness, incomplete COG schemas,
   unsupported geometry, unknown sections, unrepresentable exports all fail
   with a specific diagnostic (F-01 exit 2/3/4 discipline).
5. **Unknown stays unknown** — `Unknown` / `unavailable` / ambiguous are
   first-class diagnostic states (F-10, F-13), never collapsed to zero/false.
6. **Shared commands** — GUI, CLI, and MCP call the same core edit commands;
   transports hold no domain logic. File-based agent edits do not synchronise
   an unsaved GUI document.
7. **Synthetic fixtures only** — Relay Outpost, four-room mission, and
   lighting/UV fixtures are recreated as original port fixtures.
