# SED-MotS is archived

SED-MotS is no longer developed. Its work continues as RED on this repository's default branch, `red/main`.

This branch, `sed-mots/main`, keeps SED-MotS's final state. It was `main` before the repository became RED.
The `codex/*` branches carry SED-MotS's pull requests to smlu/SED and are kept as they are.

RED's earlier repository, with its releases up to 0.8.2, its other branches and its pull requests, is archived at
https://github.com/CodaLilitari/RED-archive.
